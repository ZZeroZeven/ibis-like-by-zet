# Zet Paint
Browser drawing studio inspired by desktop/mobile painting workflows.

## Features
- Brush and eraser with size/opacity
- Color picker and palette
- Fill bucket and eyedropper
- Undo/redo
- Zoom and pan
- Canvas resizing
- PNG export
- Save/load project JSON
- Responsive touch-friendly UI
- Automatic GitHub Pages deployment

Open the Pages URL from **Settings → Pages** after the first successful workflow run.
